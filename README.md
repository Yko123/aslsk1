# ASLSK Game Tutor

A small browser-based tutor prototype for learning ASLSK topics in sequence: Movement, Fire, and Rout. Each lesson has an explanation, a scenario, and a knowledge check. Progress is saved in the browser.

The lesson text is a draft and should be checked against the ASLSK #1 rulebook before being treated as authoritative.

## Run it

```sh
npm install
npm run dev
```

The app runs locally in the browser. It has no AI connection and sends no lesson answers anywhere.
